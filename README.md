# VAASTU — Luxury Real Estate Redefined

![VAASTU Banner](https://images.unsplash.com/photo-1600585154340-be6161a56a0c?auto=format&fit=crop&q=80&w=1200)

> "Not Just Homes. A Statement of Who You Are."

VAASTU is a high-fidelity, cinematic landing page for a premier luxury real estate brand. Rooted in the ancient wisdom of Vastu Shastra and refined by modern architectural excellence, this platform offers an immersive digital experience that mirrors the sophistication of the properties it represents.

## ✨ Key Features

- **3D Cinematic Scroll**: An immersive hero experience powered by frame-sequence animations and GSAP-like scroll triggers.
- **Bento Grid Architecture**: A modern, responsive layout showcasing property highlights and premium amenities.
- **Interactive Heritage Map**: A custom-styled map implementation (Leaflet) displaying the brand's expansive portfolio across 22+ Indian cities.
- **Curtain Loader**: A heritage-themed preloader that synchronizes with high-resolution asset loading.
- **Magnetic Interactions**: Premium micro-interactions and magnetic cursor effects for an elevated UX.
- **Fluid Smooth Scroll**: Implementation of Lenis for professional-grade scrolling momentum.
- **Responsive Mastery**: Fully optimized for every device, from mobile viewports to ultra-wide desktop monitors.

## 🛠️ Technology Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Runtime**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion 12](https://www.framer.com/motion/)
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)
- **Maps**: [React Leaflet](https://react-leaflet.js.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ayush07571/VAASTU-landing-page.git
   cd VAASTU-landing-page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open the application:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the project.

## 📁 Project Structure


## 💎 Design Philosophy

The design of VAASTU centers around **"Modern Heritage"**. By blending traditional Indian aesthetics with contemporary minimalism, the interface utilizes:
- **Rich Palettes**: Deep "Raat" blacks, "Cream" textures, and "Sona" gold accents.
- **Typography**: A mix of elegant Serifs for storytelling and clean Sans-serifs for utility.
- **Cinematic Pacing**: Animations designed to breathe, giving the user time to absorb the architectural details.
